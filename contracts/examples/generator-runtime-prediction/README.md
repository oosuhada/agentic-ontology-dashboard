# Generator Runtime Prediction Stage & Result Examples

이 디렉터리는 `systems/generator`의 Runtime Prediction Stage(내부 staging/checkpoint) 및 Model Prediction Result 규격을 나타내는 예시 자산을 포함합니다.

- `prediction-results.json`: `generator-model-prediction-result.schema.json`을 준수하는 모델별 score 및 실행 상태 결과 배열 예시
- `generator-runtime-prediction-stage.json`: `generator-runtime-prediction-stage.schema.json`을 준수하는 Generator 내부 단일 설비 모델 결과 묶음 staging payload 예시
